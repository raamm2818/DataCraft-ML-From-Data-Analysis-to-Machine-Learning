# 📊 DataCraft ML | From Data Analysis to Machine Learning

A hands-on **Python Data Analysis and Machine Learning notebook** covering the journey from working with raw data to building predictive models.

This notebook was created as part of my practical learning journey in **Python, Data Analysis, Data Science, and Machine Learning**.

Instead of focusing on a single dataset or algorithm, this notebook brings together multiple concepts and experiments to understand how data is handled, cleaned, visualized, transformed, and finally used for prediction.

---

## 🔍 What This Notebook Covers

### 🐍 Python & NumPy

- NumPy arrays
- Array operations
- Random number generation
- Array filtering
- Statistical operations

### 🐼 Pandas

- Series
- DataFrames
- CSV file handling
- Excel file handling
- Data inspection
- Sorting and filtering
- GroupBy operations
- Aggregation
- Adding and modifying columns
- Renaming and removing columns

### 🧹 Data Cleaning

Practical experiments with:

- Missing values
- Duplicate records
- Invalid values
- Data type conversion
- String cleaning
- Forward filling
- Mean and mode imputation
- Outlier-like values
- Categorical data transformation

### 📊 Data Visualization

Explored different visualization techniques using **Matplotlib** and **Seaborn**:

- Line charts
- Bar charts
- Pie charts
- Histograms
- Heatmaps
- Count plots
- Pair plots
- Box plots

### 🔤 Feature Encoding

Worked with categorical data using:

- Label Encoding

### 🤖 Machine Learning

The notebook also moves from data analysis into predictive modeling.

Algorithms and concepts explored include:

- Linear Regression

- Support Vector Regression (SVR)
- Feature scaling
- Train-test splitting
- Model prediction

### 📈 Model Evaluation

Explored basic regression evaluation metrics:

- R² Score
- Mean Squared Error (MSE)
